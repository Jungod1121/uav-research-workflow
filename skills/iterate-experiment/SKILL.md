# Iterate Experiment — 半自动实验闭环

角色：你是循环的执行者与记录者。每一轮 = `run-experiment` → `analyze-results` → 决策。**gate 规则：连续 N 轮（默认 N=5）后必须停下汇总**，这是用户明确选择的半自动化边界。

## 启动条件

- 已存在一份 `diagnosis_report.md`（或用户直接给出优化目标，如"把转角超调降到 0.3m 以内"）；
- 明确本轮的**目标函数**：一个可测量的指标 + 方向（如 `corner_overshoot_max ↓`、`mission_time ↓` 且不劣化其他指标）。

## 每轮流程

```
┌──────────────────────────────────────────────┐
│ 1. 读上一轮 diagnosis_report.md 的"下一步建议"   │
│ 2. 制定本轮改动：Hydra 风格 key=value 覆盖列表    │
│    （每轮改动 ≤2 个变量——一次改太多无法归因）      │
│ 3. run-experiment 执行（配置覆盖传入）            │
│ 4. analyze-results 出诊断                        │
│ 5. 对比目标函数：改善/持平/恶化                   │
│ 6. 记录到 iterations.md（见下）                  │
└──────────────────────────────────────────────┘
```

## Gate 与终止条件（任一满足即停）

1. **轮数上限**：连续 N=5 轮完成；
2. **目标达成**：目标函数达标且复跑一轮确认稳定（防止偶然）；
3. **恶化熔断**：连续 2 轮显著恶化 → 回滚到历史最优配置后停止；
4. **人工中断**：用户随时说停。

## iterations.md 记录格式

```markdown
| 轮 | 配置覆盖 | 目标函数值 | 较上轮 | 结论代号(F1-F6) | bag路径 |
|---|---|---|---|---|---|
| base | (无) | overshoot=0.82m | — | F2 | experiments/...-square |
| 1 | mission.speed=1.0 | overshoot=0.55m | ↓33% | F2 | experiments/... |
```

## 最终汇报（触发 gate 后必做）

按以下结构向用户汇报，附全部证据路径：

1. **最优配置**（key=value 全量列出，可直接写进论文 repro checklist）;
2. **收敛轨迹表**（iterations.md 内容）;
3. **剩余问题**：未解决项 + 你的假设 + 建议的人工介入点;
4. **诚实声明**：哪些结论置信度高（多轮一致）、哪些是单轮观察。

## 红线

- 禁止修改算法源码来"凑指标"——只允许改配置层；确需改代码时停下来请示；
- 禁止删除或覆盖历史实验目录（它们是归因依据）;
- 每轮 bag 都要落盘，禁止只存最终结果。
