# Reproduce Paper — 论文复现方法论

目的：复现不是"跑通就行"，而是**验证工具链承接外部研究代码的能力**，并为后续研究增量建立基线。每篇论文按本决策树执行，避免每次重新踩坑。

## 第一步：选型四问（决定复现代价）

1. **栈同构度**：论文环境与我们的栈 (Humble + gz-harmonic + PX4 SITL + uXRCE) 重合多少？官方是否有 ROS2/Humble 分支？
2. **代码可获得性**：开源？README 能 3 分钟跑通？（"Quick Start within 3 Minutes" 类仓库优先）
3. **指标可获得性**：论文有哪些可复现的定量指标（跟踪误差/规划时间/成功率）？我们有对应度量工具吗（edge_metric 可扩展性）？
4. **仿真独立性**：自带仿真/数据集？（自带 = L1 门槛低；依赖特定仿真器/硬件 = 成本翻倍）

## 第二步：三级复现策略

| 级别 | 内容 | 验收 | 产出 |
|---|---|---|---|
| **L1 算法级** | 在论文自带环境中跑通，复现论文指标 | 论文图表数字在同一量级 | 复现报告 + 指标记录 |
| **L2 系统级** | 接入我们的 PX4+Gazebo 执行栈，用血缘/edge_metric 重新度量 | 与 L1 指标对齐或解释偏差 | 双 bag + 对照表 |
| **L3 研究级** | 在 L2 上做我们的增量，对标该基线 | 新指标优于基线或揭示 trade-off | 论文素材 |

红线：L1 未绿不得进 L2；L2 指标偏差必须归因（环境差/版本差/参数差）后才能进 L3。

## 第三步：生态错配决策树（ROS1/旧仿真器/缺失依赖）

```
目标代码与本栈(Humble+gz-harmonic)不兼容时：
├─ Q1 有官方或社区 ROS2 移植？
│   ├─ 有 → 直接采用 + 冒烟验证其 README 命令（先于一切修改）
│   └─ 无 ↓
├─ Q2 仿真独立性强吗？（自带仿真器/纯数据集/不依赖真实传感器）
│   ├─ 强 → S2: 隔离容器运行原环境(如 ROS1 noetic 容器)，
│   │        自写薄桥(≤3 个话题)把输出转成本栈接口
│   └─ 弱 ↓
└─ S3: 移植核心算法到本栈（贵，但沉淀为自有资产；
        仅当该算法是后续研究的核心依赖时选择）
```

**已知案例**：
- EGO-Planner (ZJU-FAST-Lab)：官方 `ego-planner-swarm` 的 `ros2_version` 分支；社区 Humble 移植 `Kaede-Rukawa/ego_planner_ros_humble`；需 CycloneDDS（进程级 `RMW_IMPLEMENTATION` 即可，勿动全局）；自带 mockamap+fake_drone 仿真，L1 无需 Gazebo
- Fast-Planner：仅 ROS1，且绑定 Gazebo Classic → 按 S2 或等社区移植
- minisnap_LADRC (`yihuanghuan/minisnap_LADRC`)：ROS2 Humble 原生，与我们栈 100% 同构，热身首选

**桥接铁律**：薄桥只转发数据（话题→话题），不承载逻辑；桥接层单独成包、单独测试；桥接本身也要进血缘记录（标注"经桥转换，非原生 DDS"）。

## 留痕铁律（每次实验强制）

实验全过程必须留下三类痕迹，缺一即在报告中标注违规：
1. **截图**：关键时刻（起飞/穿越/到达/异常）的 RViz/Gazebo/监控台画面
2. **结果图**：轨迹图/误差曲线/对比图（脚本生成，禁止手工截图代替数据图）
3. **数据**：原始 bag + 指标 JSON/CSV + 规划耗时序列，全部入 experiments/ 血缘目录

## 第四步：流程与产出

1. **环境**：按论文 README 冒烟 → 记录与本栈的差异清单（进复现报告）
2. **实验**：L1/L2 各至少 3 次运行；bag + metadata.json 血缘（`paper_id` 字段 = arXiv 号）
3. **分析**：指标对照表（论文值 vs 我们复现值，含运行环境差异说明）
4. **产出**：`experiments/<id>-repro-<论文名>/` + 复现报告；对照表可直进论文 related-work/baseline

## 诚实边界

- 复现值与论文值的偏差：优先怀疑环境差异（仿真器版本/参数/随机种子），其次才怀疑论文问题；归因写入报告
- 论文未开源的部分永远不"脑补实现"——在报告中标注 [未开源，无法复现]
